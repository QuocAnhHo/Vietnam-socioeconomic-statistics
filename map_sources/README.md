`provinces.geojson` is the provider's simplified geometry, downloaded on 28 September 2026. Original metadata is in `metadata.json`. The preparation script reduces coordinate precision to five decimal places and replaces feature properties with a checked name crosswalk. It does not add or merge polygons. The renderer reverses polygon winding when necessary for D3's spherical projection.

The 2020 map is used only as a historical reference for 2009–2024; this does not assert exact boundary harmonisation for those years. Maps are disabled outside that range. All original series remain available in tables and charts. The Hue label is a display alias for the Thua Thien Hue polygon, supported by Resolution 175/2024/QH15, not a data aggregation.

The supplied geometry may omit offshore features. Its display does not determine or endorse territorial claims. Cite the original provider, licence and modifications when reusing it.
